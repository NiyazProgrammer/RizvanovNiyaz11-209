# Deployment / запуск краулера (Deployment Man)

Краткая инструкция для того, кто **первый раз разворачивает** проект или **проверяет сдачу** без чтения исходников.

## Что должно быть на машине

| Требование | Проверка |
|------------|----------|
| Python 3.10+ (желательно 3.11+) | `python3 --version` |
| Сеть (доступ к `https://habr.com`) | браузер или `curl -I https://habr.com` |

## Установка и запуск (с нуля)

```bash
cd /path/to/RizvanovNiyaz11-209
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python crawl.py
```

Ожидаемое поведение:

1. В консоли — фаза 1 (счётчик уникальных статей по каждой seed-странице), затем фаза 2 (`downloaded 10/100` … `100/100`).
2. Код выхода `0`. При нехватке URL — сообщение `ERROR: only N...` и код `1`.

**Время:** порядка нескольких минут из‑за пауз между запросами (~0.5–1.5 с на запрос; сотни HTTP-запросов).

## Где лежит результат

| Артефакт | Назначение |
|----------|------------|
| `corpus/001.txt` … `corpus/100.txt` | Сырой HTML страниц статей (разметка не удаляется). |
| `index.txt` | Соответствие: `номер<TAB>полный_URL` (UTF-8). |
| `seed_urls.txt` | Список URL лент, с которых собирались ссылки на статьи. |

## Проверка без запуска кода

Преподаватель может убедиться в выполнении задания, открыв файлы в репозитории:

1. **`index.txt`** — должно быть **не менее 100** строк; каждая начинается с числа и табуляции, далее URL `https://habr.com/ru/...`.
2. **`corpus/001.txt`** (и несколько других) — в начале файла виден HTML (`<!DOCTYPE` или `<html`), текст на русском (`lang="ru"` в типичном случае).
3. Сопоставление: строка `N` в `index.txt` соответствует файлу `corpus/NNN.txt`, где `NNN` — номер с ведущими нулями (например, `1` → `001.txt`).

Команды для быстрой проверки в терминале (опционально):

```bash
wc -l index.txt          # ожидается 100
ls corpus | wc -l        # ожидается 100
head -n 3 index.txt
head -n 5 corpus/001.txt
```

## Конфигурация

- Минимальное число статей: константа `MIN_ARTICLES` в `crawl.py` (по умолчанию 100).
- Список лент: только `seed_urls.txt` (можно добавить строки `https://habr.com/ru/articles/pageN/`, если уникальных статей не хватает).

- Если корпус большой и не коммитится в Git — в коммите указать: код + `DEPLOYMENT.md`; выкачку приложить отдельно по требованиям курса.

## Соответствие robots.txt

Краулер делает умеренное число запросов с задержками и идентифицируемым `User-Agent`. Перед промышленным использованием имеет смысл свериться с актуальным `https://habr.com/robots.txt`.
